# Derivative Reconciliation System (DRS)

A Streamlit-based reconciliation platform built using Python, Pandas, and Plotly.

## Features

- Source vs Target reconciliation
- Match and Break identification
- Missing transaction detection
- Aging analysis
- Escalation tracking
- Priority classification
- Exception dashboard
- Visualization using Plotly
- Excel report downloads

## Technology Stack

- Python
- Streamlit
- Pandas
- OpenPyXL
- Plotly
